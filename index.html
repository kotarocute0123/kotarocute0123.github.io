お釣りのこうちゃん 投稿ツール

このツールは、運営者本人のYouTubeチャンネルに、シーバス釣りの解説ショート動画をアップロードするための個人用ツールです。

運営者が制作した動画を、YouTube Data API を使って運営者自身のチャンネルへアップロードします。運営者以外の方がこのツールを使うことはありません。

使用するデータ

  • YouTube Data API の動画アップロード権限、および再生リストの管理権限（運営者自身のチャンネルのみ）

詳しくは プライバシーポリシー をご覧ください。

本ツールは YouTube API サービスを使用しています。YouTube 利用規約 ／ Google プライバシーポリシー

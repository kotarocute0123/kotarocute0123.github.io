プライバシーポリシー

制定日：2026年10月7日

「お釣りのこうちゃん 投稿ツール」（以下、本ツール）は、運営者本人のYouTubeチャンネルへ動画をアップロードするための個人用ツールです。

1. 取得する情報

本ツールは、Google の OAuth 認証を通じて、運営者本人の Google アカウントについて次の権限を取得します。

  • YouTube への動画のアップロード
  • YouTube の再生リストへの動画の追加

運営者以外の利用者の情報は取得しません。

2. 利用目的

取得した権限は、運営者が制作した動画を運営者自身のチャンネルへアップロードし、再生リストに追加するためだけに使用します。広告、分析、その他の目的には使用しません。

3. 保存と管理

認証情報（アクセストークン）は、運営者が管理するPCと、動画制作の自動化に使用する作業環境（Anthropic社のClaude）にのみ保存します。

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

6. YouTube API サービス

本ツールは YouTube API サービスを使用しています。利用にあたっては YouTube 利用規約 および Google プライバシーポリシー が適用されます。

7. アクセス権の取り消しとデータの削除

本ツールに与えた権限は、Google アカウントのセキュリティ設定ページ からいつでも取り消せます。

権限を取り消した場合、または本ツールの利用をやめた場合、運営者は保存している認証情報を7日以内に削除します。削除の依頼は下記の問い合わせ先でも受け付けます。
